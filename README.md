# fast-llm-summarization-api

A fast text summarization API serving `Qwen/Qwen3-4B-Instruct-2507` with vLLM behind a FastAPI gateway, packaged with Docker and deployed on a single AWS EC2 `g4dn.xlarge` (NVIDIA T4).

> **Status:** work in progress. Full documentation (architecture, API reference, benchmarks, cost) will be added as the project is built.
